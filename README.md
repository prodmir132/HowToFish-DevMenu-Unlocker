# 🎣 How to Fish — Разблокировка Dev-Меню и Админки

Этот мод-пак автоматически активирует встроенный официальный режим разработчиков в игре **How to Fish** (версия 1.0.10).

## 🎮 Что дает этот мод:
* На главном экране игры появляется скрытое меню **[Dev]** и кнопка **Developer Join**.
* Намертво включается скрытая админка создателей игры (функции тестирования).

## 🚀 Инструкция по установке:
1. Перейдите в раздел **Releases** в правой части этой страницы и скачайте актуальный `.zip` архив.
2. Распакуйте содержимое архива прямо в **корневую папку игры** (туда, где лежит файл `HowToFish.exe`).
3. Запустите игру и наслаждайтесь скрытыми функциями!

# 🎣 How to Fish — Unlocking the Dev Menu and Admin Panel

This mod pack automatically activates the built‑in official developer mode in the game **How to Fish** (version 1.0.10).

## 🎮 What this mod provides:
* A hidden **[Dev]** menu and a **Developer Join** button appear on the game’s main screen.
* The game’s creators’ hidden admin panel (testing functions) is enabled by default.

## 🚀 Installation instructions:
1. Go to the **Releases** section on the right side of this page and download the latest `.zip` archive.
2. Unpack the contents of the archive directly into the **game’s root folder** (the folder where the `HowToFish.exe` file is located).
3. Launch the game and enjoy the hidden features!

*Developed using BepInEx and Harmony.*
